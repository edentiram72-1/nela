# NELA OS API Notes

## Status

No public API has been implemented yet.

This document defines how APIs should be documented once modules begin exposing stable interfaces.

## API Documentation Requirements

Every module API should include:

- Purpose.
- Inputs.
- Outputs.
- Error behavior.
- Side effects.
- Configuration requirements.
- Example usage.
- Test coverage notes.

## Stability Levels

| Level | Meaning |
| --- | --- |
| Draft | Early design; breaking changes are expected. |
| Experimental | Usable internally, but still changing. |
| Stable | Safe for other modules to depend on. |
| Deprecated | Scheduled for replacement or removal. |

## Current APIs

No APIs are currently defined.
