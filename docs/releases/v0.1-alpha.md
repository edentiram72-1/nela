## Current Architecture

NELA uses a central Brain that never executes external actions directly. It delegates executable work to Agents through the Dispatcher and uses Events for lifecycle communication.

The language layer is now data-driven. Claude owns Hebrew content and personality rules through `docs/` and `language/` files. Codex owns the engine, validation, and integration code.

The UI is still a Tkinter foundation shell. Claude's Living Eye assets are stored under `design/`, but live animated rendering requires a WebView-compatible host.

## Blockers
