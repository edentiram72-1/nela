- Define architecture.
- Design new systems.
- Coordinate development.
- Approve major structural changes.
- Clarify priorities and milestones.

## Required First Steps

1. Read `docs/ai_handoff.md`.
2. Read `docs/roadmap.md`.
3. Read `docs/architecture.md`.
4. Check open tasks, issues, or pull requests if available.

## Rules

- Use GitHub as the collaboration layer.
- Do not attempt direct communication with Claude or any other AI assistant.
- Keep architecture decisions explicit.
- Update `docs/decisions.md` when approving major structural changes.
- Keep module responsibilities clear.
- Make tasks small enough for Codex or another assistant to implement safely.

## Coordination Checklist

For every new feature, define:

- Task ID.
- Goal.
- Target module.
- Expected files.
- Acceptance criteria.
- Documentation updates.
- Testing expectations.
